# DC Felony Arrests 2016

Interactive dashboard of 2016 felony arrests by the Metropolitan Police Department in Washington, DC, filterable by police district, charge category, race, sex and month.

**Live dashboard:** https://mngoh.github.io/DC-Crime-Data-2016/

- `notebooks/` — EDA, geospatial plots, chi-square tests and an ML model
- `scripts/` — data processing
- `data/` — 2016 felony arrest charges and felony crime incidents, plus the DC boundary shapefile
